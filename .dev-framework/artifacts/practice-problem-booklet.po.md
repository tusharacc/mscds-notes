## Problem Statement

The user has two probability textbook PDFs without worked solutions. The goal is to extract
the exercises, generate hints and full step-by-step solutions (verified against web sources),
and produce a polished GitHub Pages HTML file plus a printable PDF booklet.

## Source Material
- `ProbabilityChapter/mit_notes_probability.pdf` — 196 pages, text-based LaTeX
- `ProbabilityChapter/probability_chapter_notes.pdf` — 39 pages, text-based
