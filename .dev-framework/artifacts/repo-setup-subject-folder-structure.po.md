# PO Artifact: repo-setup-subject-folder-structure

## Problem Statement

The MScDS notes project needs a public GitHub remote repository with a clean
subject-based folder structure. Videos and transcripts exist locally and must be
organised per subject. MP4 files must be excluded from git. A README must link
to the rendered HTML notes via GitHub Pages (or raw.githubusercontent).

## User Stories

- As a student, I want a public repo so I can access notes from any device.
- As a future contributor, I want subject folders so new weeks can be added without restructuring.
- As a reader, I want a README link that opens the rendered HTML directly in browser.
