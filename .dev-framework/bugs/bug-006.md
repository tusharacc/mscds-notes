# Root `.gitignore` doesn't explicitly cover `lecture-capture/credentials/`

Credentials are protected by `lecture-capture/.gitignore`, but if that file is ever
removed, the credentials would become unprotected. Adding an explicit entry to the
root `.gitignore` provides defence-in-depth.

**Recommended fix:** Add `lecture-capture/credentials/` to root `.gitignore`.
