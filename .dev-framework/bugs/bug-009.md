# BUG-009 — Summary truncation appends ellipsis even for short questions

**Severity:** low
**Status:** open
**Feature:** mcq-quiz-for-python-course
**File:** python/quiz/index.html

## Description
In renderSummary(), question text is truncated with `.substring(0, 80) + '…'` unconditionally. For questions shorter than 80 characters (after HTML stripping), the ellipsis is still appended, producing output like "What is a list?…"

## Fix
Change the truncation line to:
```js
const preview = stripped.length > 80 ? stripped.substring(0, 80) + '…' : stripped;
```
