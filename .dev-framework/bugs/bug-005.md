# `lecture-capture/config.yaml` has a plaintext password field in public repo

`config.yaml` contains `obs.websocket_password: ""` — currently empty, but now publicly
visible. If a user sets the password and commits, it would be exposed.

**Recommended fix:** Rename to `config.yaml.example` (committed as template), add
`lecture-capture/config.yaml` to root `.gitignore` so the live config is local-only.
