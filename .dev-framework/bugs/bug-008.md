# BUG-008 — Option buttons lack aria-pressed state

**Severity:** low
**Status:** open
**Feature:** mcq-quiz-for-python-course
**File:** python/quiz/index.html

## Description
When the user selects an option, the button receives a `selected` CSS class visually, but no `aria-pressed` attribute is set. Screen readers cannot communicate which option is currently selected to the user.

## Fix
On option click: set `aria-pressed="false"` on all option buttons, then `aria-pressed="true"` on the selected one. Initialize all buttons with `aria-pressed="false"` when rendering the question.
