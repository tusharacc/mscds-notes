# BUG-007 — No aria-live region for quiz feedback

**Severity:** low
**Status:** open
**Feature:** mcq-quiz-for-python-course
**File:** python/quiz/index.html

## Description
After submitting an answer, the correct/wrong result badge and explanation appear visually but are not announced to screen readers. Users relying on assistive technology receive no feedback about whether their answer was right or wrong.

## Fix
Add `aria-live="polite"` (or `aria-live="assertive"`) to the explanation container div that is injected after answer submission. Alternatively, wrap the result badge in a dedicated live region.
