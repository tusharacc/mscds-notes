# Week banner CSS missing for future weeks (6, 7, 8…)

Only `.week-section[data-week="4-5"] .week-banner` is defined. When Week 6+ content is added with `data-week="6"`, the banner will render without a background color or accent border. The template comment should include the CSS snippet to add alongside each new week section.
