1 · Classical Probability & Equally Likely Outcomes

Definition
Sample Space and Event
A sample space \(S\) is the set of all possible outcomes of an experiment. An event \(E\) is any subset \(E \subseteq S\).
Axiom
Kolmogorov Axioms of Probability
For any event \(E \subseteq S\):
  1. \(P(E) \geq 0\)
  2. \(P(S) = 1\)
  3. For mutually disjoint events \(E_1, E_2, \ldots\): \(\displaystyle P\!\left(\bigcup_i E_i\right) = \sum_i P(E_i)\)
Key Formula
Equally Likely Outcomes
When every outcome in \(S\) is equally likely: \[P(E) = \frac{|E|}{|S|} = \frac{\text{number of outcomes in } E}{\text{total number of outcomes}}\]
Example
Fair Die — Even Outcomes
\(S = \{1,2,3,4,5,6\}\), \(E = \{2,4,6\}\). \[P(E) = \frac{|E|}{|S|} = \frac{3}{6} = \frac{1}{2}\]
Example
Fair Coin — Equal Probability Assumption
For a coin toss, \(S = \{H, T\}\). We assume \(P(H) = P(T) = \tfrac{1}{2}\). This is an assignment, not a physical law — in practice many factors (coin geometry, toss force, air) affect the true probability, but the fair-coin model is the standard assumption. The IPL match coin-toss example from lecture illustrates that we assign this value even without certainty about the physical outcome.
Axiom
Monotonicity
If \(E \subseteq F\) then \(P(E) \leq P(F)\). Proof: \(F = E \cup (F \setminus E)\) is a disjoint union, so \(P(F) = P(E) + P(F \setminus E) \geq P(E)\).

2 · Combinatorial Probability

Definition
Binomial Coefficient
\(\displaystyle\binom{n}{k} = \frac{n!}{k!\,(n-k)!}\) — number of ways to choose \(k\) items from \(n\) without regard to order.
Example
N Balls, K Picks — Probability of Picking the Special Ball

A bag has \(N\) balls, exactly one special. Pick \(K\) balls. What is \(P(\text{special ball picked})\)?

Derivation 1 — First Principles (Sequential)

Represent picks as \(\mathbf{e} \in \{0,1\}^K\) where \(1\) = special (at most once). Event \(E\): the \(K\) strings with exactly one \(1\).

For e.g. \((1,0,0,\ldots,0)\): pick special first (\(\tfrac{1}{N}\)), then all remaining are non-special (prob 1 each round):

\[\frac{1}{N} \cdot 1 \cdot 1 \cdots = \frac{1}{N}\]

\(|E| = K\) (one position for the \(1\)), so:

\[P(E) = K \cdot \frac{1}{N} = \frac{K}{N}\]
Derivation 2 — Combinatorial Shortcut \[P(E) = \frac{\binom{1}{1}\binom{N-1}{K-1}}{\binom{N}{K}} = \frac{\frac{(N-1)!}{(K-1)!(N-K)!}}{\frac{N!}{K!(N-K)!}} = \frac{K}{N}\]

Result: \(\displaystyle P(\text{special ball picked}) = \dfrac{K}{N}\)

Example
52-Card Deck — Exactly 3 Red and 3 Black from 6 Picks

Deck: 26 red + 26 black cards. Pick 6. \(P(\text{exactly 3 red and 3 black})\)?

Derivation 1 — First Principles

Represent picks as \(\mathbf{e}\in\{0,1\}^6\) (0=red, 1=black). For the specific sequence \((0,0,0,1,1,1)\):

\[P = \frac{26}{52}\cdot\frac{25}{51}\cdot\frac{24}{50}\cdot\frac{26}{49}\cdot\frac{25}{48}\cdot\frac{24}{47}\]

All \(\binom{6}{3} = 20\) balanced sequences share the same probability, so:

\[P(E) = \binom{6}{3} \cdot \frac{(26 \cdot 25 \cdot 24)^2}{52 \cdot 51 \cdot 50 \cdot 49 \cdot 48 \cdot 47}\]
Derivation 2 — Combinatorial \[P(E) = \frac{\binom{26}{3}\binom{26}{3}}{\binom{52}{6}}\] Expanding confirms equality with Derivation 1.

Result: \(\displaystyle P(E) = \dfrac{\binom{26}{3}^2}{\binom{52}{6}} \approx 0.3251\)

Definition
Sample Space as Ordered Vectors
Representing outcomes as ordered vectors (rather than sets) preserves position integrity — e.g. \((0,1,0,0,1,1)\) differs from \((1,0,0,0,1,1)\) because pick order matters for computing sequential probabilities.
Practice More problems of this type appear in the problem set. Always try first-principles derivation before applying shortcut formulas.

3 · Sample Space Construction

Definition
Two Methods
  1. Enumeration — list all outcomes directly as tuples/vectors.
  2. Tree method — branch at each sequential decision; each root-to-leaf path is one outcome. The probability of a leaf = product of edge probabilities along its path.
Example
Monty Hall — Tree-Based Sample Space

Three doors A, B, C. Car behind one door (uniformly random). Contestant picks a door. Host opens a goat-door (uniformly among valid choices if two are available).

Each outcome: (car location, contestant pick, door host opens).

Full 12-outcome sample space
  • Car location: A, B, or C each with prob \(\tfrac{1}{3}\)
  • Contestant pick: A, B, or C each with prob \(\tfrac{1}{3}\)
  • Host: prob 1 when forced, \(\tfrac{1}{2}\) each when two goat-doors remain
Outcome Probability Switch wins?
(A,A,B)\(\tfrac{1}{18}\)No
(A,A,C)\(\tfrac{1}{18}\)No
(A,B,C)\(\tfrac{1}{9}\)Yes
(A,C,B)\(\tfrac{1}{9}\)Yes
(B,A,C)\(\tfrac{1}{9}\)Yes
(B,B,A)\(\tfrac{1}{18}\)No
(B,B,C)\(\tfrac{1}{18}\)No
(B,C,A)\(\tfrac{1}{9}\)Yes
(C,A,B)\(\tfrac{1}{9}\)Yes
(C,B,A)\(\tfrac{1}{9}\)Yes

(C,C,B)\(\tfrac{1}{18}\)No
Sum \(= 6 \cdot \tfrac{1}{18} + 6 \cdot \tfrac{1}{9} = \tfrac{1}{3} + \tfrac{2}{3} = 1\). ✓
\[P(\text{win by switching}) = 6 \times \frac{1}{9} = \frac{2}{3}\]

Counter-intuitive result: always switch — win with prob \(\tfrac{2}{3}\) vs. \(\tfrac{1}{3}\) if you stay.

4 · Conditional Probability

Definition
Conditional Probability
The probability of event \(E\) given that \(F\) occurred: \[P(E \mid F) = \frac{P(E \cap F)}{P(F)}, \quad P(F) > 0\] Equivalently: \(P(E \cap F) = P(E \mid F)\,P(F)\).

Philosophically, conditioning on \(F\) makes \(F\) the new universe; \(E \cap F\) is the event of interest within it.

Example
Two Coins — Conditioning on Distinct Outcomes

\(S = \{HH, HT, TH, TT\}\), all equally likely.

  • \(E\) = outcomes distinct = \(\{HT, TH\}\), \(P(E) = \tfrac{1}{2}\)
  • \(F\) = first toss is H = \(\{HH, HT\}\), \(P(F) = \tfrac{1}{2}\)
\[P(F \mid E) = \frac{P(F \cap E)}{P(E)} = \frac{P(\{HT\})}{P(\{HT,TH\})} = \frac{1/4}{1/2} = \frac{1}{2}\]
Example
Two Dice — P(at least one die odd | sum is even)

\(|S|=36\). Even sum requires both dice odd or both even. \(|F|=18\), \(P(F)=\tfrac{1}{2}\).

\(E \cap F\) = both dice odd (9 outcomes), since odd+even = odd ≠ even.

\[P(E \mid F) = \frac{9/36}{18/36} = \frac{1}{2}\]
Practice Complete the full sample space enumeration for this problem.
Example
Red & Blue Balls Without Replacement — P(first is blue | k of n are blue)

Bag: \(R\) red + \(B\) blue. Pick \(n\) without replacement. \(E\) = first is blue, \(F\) = exactly \(k\) of the \(n\) are blue.

Full derivation \[P(E \cap F) = \frac{B}{R+B} \cdot \frac{\binom{B-1}{k-1}\binom{R}{n-k}}{\binom{R+B-1}{n-1}}, \qquad P(F) = \frac{\binom{B}{k}\binom{R}{n-k}}{\binom{R+B}{n}}\] After factorial cancellation: \[P(E \mid F) = \frac{k}{n}\]

Result: \(\displaystyle P(\text{first blue} \mid k \text{ of } n \text{ are blue}) = \dfrac{k}{n}\)

Intuition: by symmetry, any of the \(n\) positions is equally likely to be blue, so position 1 is blue with prob \(k/n\).

5 · Law of Total Probability

Theorem
Two-Part Version
For any event \(A\) with \(0 < P(A) < 1\): \[P(E) = P(E \mid A)\,P(A) + P(E \mid A^c)\,P(A^c)\] Follows from \(E = (E \cap A) \cup (E \cap A^c)\), a disjoint union.
Theorem
General (Partition) Version
If \(\{F_1, \ldots, F_\ell\}\) is a partition of \(S\): \[P(E) = \sum_{i=1}^{\ell} P(E \mid F_i)\,P(F_i)\] This generalization (from week 5) shows you can use any finer partition of the hypothesis space — not just \(F\) and \(F^c\).

6 · Bayes' Theorem

Theorem
Bayes' Rule
\[P(F \mid E) = \frac{P(E \mid F)\,P(F)}{P(E \mid F)\,P(F) + P(E \mid F^c)\,P(F^c)}\]

Derivation: from \(P(E \cap F) = P(E \mid F)P(F) = P(F \mid E)P(E)\), solve for \(P(F \mid E)\) and expand \(P(E)\) via total probability.

\(P(F)\) = prior;  \(P(F \mid E)\) = posterior after seeing evidence \(E\).

Example
Monty Hall — Bayes' Rule Approach

\(H\) = "initial pick is the car" (\(P(H)=\tfrac{1}{3}\)). \(E\) = "host opens a goat door" (always happens, so \(P(E\mid H)=P(E\mid H^c)=1\)).

\[P(H \mid E) = \frac{1 \cdot \tfrac{1}{3}}{1\cdot\tfrac{1}{3} + 1\cdot\tfrac{2}{3}} = \frac{1}{3}\]

\(P(H^c \mid E) = \tfrac{2}{3}\) — switching wins with prob \(\tfrac{2}{3}\). Confirms the tree result.

Example
Student Knows the Answer

Student knows answer with prob \(p\); guesses correctly with prob \(\tfrac{1}{m}\) if not. \(E\) = correct, \(F\) = knows.

\[P(F \mid E) = \frac{1 \cdot p}{1 \cdot p + \tfrac{1}{m}(1-p)} = \frac{mp}{p(m-1)+1}\]

Result: \(\displaystyle P(\text{knows} \mid \text{correct}) = \dfrac{mp}{p(m-1)+1}\). As \(m\to\infty\), this approaches 1.

Example
Medical Diagnostic Test

Test: 95% accurate (\(P(+\mid D)=0.95\)), false-positive rate 1% (\(P(+\mid D^c)=0.01\)), disease prevalence 0.5% (\(P(D)=0.005\)).

Full derivation \begin{align*} P(D \mid +) &= \frac{0.95 \times 0.005}{0.95 \times 0.005 + 0.01 \times 0.995} \\[6pt] &= \frac{0.00475}{0.00475 + 0.00995} = \frac{95}{294} \approx 0.323 \end{align*}

~32% chance of disease given a positive result. The low prior \(P(D)\) dominates — this is the base rate fallacy.

Example
Police Inspector — Suspect Guilt

\(P(G)=0.6\) (inspector's prior). Evidence: crime was committed by a left-handed person; \(P(C\mid G)=1\). Base rate of left-handedness \(P(C)\approx 0.2\).

Derivation using inequality

Left-handedness among the innocent population is at most the base rate, so \(P(C \mid G^c) \leq 0.2\). Using Bayes:

\[P(G \mid C) \geq \frac{1 \times 0.6}{1 \times 0.6 + 0.2 \times 0.4} = \frac{0.6}{0.68} = \frac{60}{68}\]

Result: \(\displaystyle P(\text{guilty} \mid \text{left-handed}) \geq \dfrac{60}{68} \approx 0.882\)

First use of an inequality inside Bayes — because we only have an upper bound on \(P(C \mid G^c)\).

7 · Chain Rule (Multiplication Rule)

Theorem
Chain Rule of Probability
\[P\!\left(\bigcap_{i=1}^n E_i\right) = \prod_{i=1}^{n} P\!\left(E_i \,\middle|\, \bigcap_{j=1}^{i-1} E_j\right)\] Base case: \(P(E_1 \cap E_2) = P(E_2 \mid E_1)\,P(E_1)\). Extend inductively.
Example
Red and White Balls — Chain Rule in Three Steps

Bag: 8 red + 4 white (12 total). Pick without replacement. \(E_1, E_2\) = red, \(E_3\) = white.

P(first two red) \[P(E_1) = \frac{8}{12}, \quad P(E_2 \mid E_1) = \frac{7}{11} \implies P(E_1 \cap E_2) = \frac{8}{12}\cdot\frac{7}{11} = \frac{14}{33}\]
P(first two red, third white)

10 balls remain: 6 red + 4 white. \(P(E_3 \mid E_1 \cap E_2) = \tfrac{4}{10}\).

\[P(E_1 \cap E_2 \cap E_3) = \frac{4}{10} \cdot \frac{14}{33} = \frac{28}{165}\]

Results: \(P(\text{first 2 red}) = \tfrac{14}{33}\), \(\quad P(\text{first 2 red, 3rd white}) = \tfrac{28}{165}\)

8 · Independence of Events

Definition
Two Events Independent
\(E\) and \(F\) are independent if: \[P(E \mid F) = P(E) \quad \Longleftrightarrow \quad P(E \cap F) = P(E)\,P(F)\]
Axiom
Mutual Independence (Product Rule)
\(E_1, \ldots, E_n\) are mutually independent if for every subset \(I \subseteq \{1,\ldots,n\}\): \[P\!\left(\bigcap_{i \in I} E_i\right) = \prod_{i \in I} P(E_i)\] Pairwise independence does not imply mutual independence.
Example
Sequential Coin Tosses
\[P(\text{HTTHH}) = \left(\frac{1}{2}\right)^5 = \frac{1}{32}\]

9 · Weighted / Non-Uniform Sampling

Definition
Weighted Sampling
Each item \(i\) has weight \(w_i\). Probability of selecting it: \[P(\text{item } i) = \frac{w_i}{\sum_j w_j}\] After removal, the denominator updates accordingly.
Example
Red (weight \(R\)) and White (weight \(W\)) Balls

8 red + 4 white, weights \(R\) and \(W\).

Two red picks in sequence \[P(E_1) = \frac{8R}{8R+4W}, \qquad P(E_2 \mid E_1) = \frac{7R}{7R+4W}\] \[P(E_1 \cap E_2) = \frac{8R}{8R+4W} \cdot \frac{7R}{7R+4W}\]

If second pick is white instead: \(P(E_2^{\text{white}} \mid E_1) = \dfrac{4W}{7R+4W}\).

Key insight: each draw's probability is relative to the remaining total weight. Chain rule still applies.

10 · Random Variables

Definition
Random Variable
A random variable \(X\) is a function \(X: S \to \mathbb{R}\). The range of \(X\) is the set of values it can take.
Definition
Types
  • Discrete: countable range (e.g., \(\mathbb{N}\), \(\{0,\ldots,k\}\)).
  • Indicator: \(X \in \{0,1\}\) — 1 if event occurs, 0 otherwise. Any indicator is Bernoulli.
  • Continuous: range is an interval (future lectures).
Example
Three Canonical Examples
  1. Heads in \(k\) coin tosses: range \(\{0,1,\ldots,k\}\).
  2. Die roll: \(X: \{1,\ldots,6\} \to \{1,\ldots,6\}\) (identity). Range \(= \{1,\ldots,6\}\).
  3. Tosses until first heads (Geometric): range \(= \mathbb{N} = \{1,2,3,\ldots\}\) — unbounded.
Example
Highest-Valued Ball Among 3 Picks from 20

Let \(X\) = number of highest-valued ball. Range \(= \{3,\ldots,20\}\).

\[P(X = k) = \frac{\binom{k-1}{2}}{\binom{20}{3}}, \quad k \in \{3,\ldots,20\}\] \[P(X \geq 17) = \frac{\binom{16}{2}+\binom{17}{2}+\binom{18}{2}+\binom{19}{2}}{\binom{20}{3}}\]

11 · Probability Mass Function (PMF)

Definition
PMF
\[p_v = P(X = v), \quad v \in \text{Range}(X)\]
Axiom
Normalization
\[\sum_{v \in \text{Range}(X)} P(X = v) = 1\]
Example
Two Coin Tosses — PMF of Number of Heads
\(v\) \(P(X=v)\) Outcomes
0\(\tfrac{1}{4}\)TT
1\(\tfrac{1}{2}\)HT, TH
2\(\tfrac{1}{4}\)HH
Sum: \(\tfrac{1}{4}+\tfrac{1}{2}+\tfrac{1}{4}=1\). ✓

12 · Expectation

Definition
Expected Value (Mean)
\[\mathbb{E}[X] = \sum_{v \in \text{Range}(X)} v \cdot P(X = v)\] Probability-weighted average of all values. Need not be in the range of \(X\).
Example
Die Roll: \(\mathbb{E}[X] = 3.5\)
\[\mathbb{E}[X] = \frac{1+2+3+4+5+6}{6} = \frac{21}{6} = 3.5\]

3.5 is not an outcome of the die — the expected value is an average, not a realization.

Example
Two Coin Tosses: \(\mathbb{E}[\text{heads}] = 1\)
\[\mathbb{E}[X] = 0 \cdot \tfrac{1}{4} + 1 \cdot \tfrac{1}{2} + 2 \cdot \tfrac{1}{4} = 1\]
Example
Sequential Exam Questions

Q1 worth \(V_1\), Q2 worth \(V_2\). Student can only attempt Q2 if Q1 correct. Knows Q1 with prob \(p_1\), Q2 with prob \(p_2\).

\(X\)ProbabilityScenario
0\(1-p_1\)Fails Q1
\(V_1\)\(p_1(1-p_2)\)Passes Q1, fails Q2
\(V_1+V_2\)\(p_1 p_2\)Passes both
\[\mathbb{E}[X] = p_1 V_1 + p_1 p_2 V_2\]

13 · Linearity of Expectation

Theorem
Linearity of Expectation
For any random variables \(X_1, \ldots, X_n\) (independent or dependent): \[\mathbb{E}\!\left[\sum_{i=1}^n X_i\right] = \sum_{i=1}^n \mathbb{E}[X_i], \qquad \mathbb{E}[aX] = a\,\mathbb{E}[X]\] Holds regardless of dependence structure — one of the most powerful tools in probabilistic analysis.
Example
Expected Edges in a Random Graph

\(n\) vertices; each edge exists independently with prob \(\tfrac{1}{2}\). Let \(X_{ij}=\mathbf{1}[\text{edge }(i,j)\text{ exists}]\).

\[\mathbb{E}[\text{edges}] = \sum_{i < j} \mathbb{E}[X_{ij}] = \binom{n}{2} \cdot \frac{1}{2} = \frac{n(n-1)}{4}\]
Example
Expected Triangles in a Random Graph

\(X_{ijk}=\mathbf{1}[\text{triangle on }i,j,k]\). All three edges needed, each prob \(\tfrac{1}{2}\):

\[\mathbb{E}[X_{ijk}] = \frac{1}{8} \implies \mathbb{E}[\text{triangles}] = \binom{n}{3}\cdot\frac{1}{8} = \frac{n(n-1)(n-2)}{48}\]

For edge prob \(p\): \(\mathbb{E} = \dbinom{n}{3}p^3\).

Example
Hat-Check Problem

\(m\) people, hats returned randomly. \(X_i=\mathbf{1}[\text{person }i\text{ gets own hat}]\), \(P(X_i=1)=\tfrac{1}{m}\).

\[\mathbb{E}\!\left[\sum_{i=1}^m X_i\right] = m \cdot \frac{1}{m} = 1\]

Exactly 1 person expected to get own hat, regardless of \(m\). (The \(X_i\) are highly dependent — linearity doesn't care.)

Example
Stock Price

Start ₹100. Each day: ×\(r\) with prob \(p\), ×\(\tfrac{1}{r}\) with prob \(1-p\).

Recursive expectation \[\mathbb{E}[X_i] = \left(pr + \frac{1-p}{r}\right)\mathbb{E}[X_{i-1}]\] Unrolling to day 0 (\(X_0 = 100\)): \[\mathbb{E}[X_d] = \left(pr + \frac{1-p}{r}\right)^{\!d} \times 100\]

14 · Special Distributions

14a · Bernoulli Distribution
Definition
Bernoulli\((p)\)
\(X \in \{0,1\}\), \(P(X=1)=p\), \(P(X=0)=1-p\). \(\mathbb{E}[X] = p\). Building block for Binomial. Any indicator variable is Bernoulli.
14b · Binomial Distribution
Definition
Binomial\((k,p)\)
\(X\) = successes in \(k\) independent trials each with prob \(p\). \[P(X = i) = \binom{k}{i} p^i (1-p)^{k-i}, \quad i \in \{0,\ldots,k\}\]
Theorem
PMF Sums to 1 — via Binomial Theorem
\[\sum_{i=0}^{k} \binom{k}{i} p^i (1-p)^{k-i} = (p+(1-p))^k = 1 \quad \checkmark\]
Key Formula
Expected Value via Linearity: \(\mathbb{E}[X] = kp\)

Write \(X = X_1 + \cdots + X_k\), each \(X_i \sim \text{Bernoulli}(p)\):

\[\mathbb{E}[X] = \sum_{i=1}^k \mathbb{E}[X_i] = k \cdot p\]

If trials have different probabilities \(p_i\): \(\mathbb{E}[X] = \sum_{i=1}^k p_i\).

Example
Screw Pack Quality Control

10 screws/pack, each faulty independently with prob 0.01. Pack returned if \(\geq 2\) faulty. 1 million packs sold.

Compute P(return) \begin{align*} P(X=0) &= (0.99)^{10} \approx 0.9044 \\ P(X=1) &= 10 \cdot 0.01 \cdot (0.99)^9 \approx 0.0914 \\ P(X \geq 2) &\approx 1 - 0.9044 - 0.0914 = 0.0042 \approx 0.004 \end{align*}
\[\mathbb{E}[\text{returns}] \approx 0.004 \times 10^6 = 4{,}000 \text{ packs}\]
14c · Geometric Distribution
Definition
Geometric\((p)\)
\(X\) = trials until first success (including success trial). Each trial succeeds with prob \(p\). \[P(X = i) = (1-p)^{i-1} p, \quad i \in \{1,2,3,\ldots\}\]
Theorem
PMF Sums to 1 (Geometric Series)
\[\sum_{i=1}^{\infty}(1-p)^{i-1}p = p \cdot \frac{1}{1-(1-p)} = 1 \quad \checkmark\]
Key Formula
Expected Trials to First Success
\[\mathbb{E}[X] = \frac{1}{p}\]

Uses \(\displaystyle\sum_{i=1}^{\infty} i x^{i-1} = \frac{1}{(1-x)^2}\) with \(x=1-p\). Worked out in tutorial.

15 · Markov Inequality & Tail Inequalities

Theorem
Markov's Inequality
For non-negative \(X\) and any \(a > 0\): \[P(X \geq a) \leq \frac{\mathbb{E}[X]}{a}\]
Proof sketch \[\mathbb{E}[X] \geq \sum_{v \geq a} v \cdot P(X=v) \geq a \sum_{v \geq a} P(X=v) = a \cdot P(X \geq a)\] Divide by \(a\).
Key Formula
Equivalent Forms
Setting \(a = (1+\varepsilon)\mathbb{E}[X]\): \[P\!\left(X \geq (1+\varepsilon)\,\mathbb{E}[X]\right) \leq \frac{1}{1+\varepsilon}\] In particular, \(P(X \geq 2\,\mathbb{E}[X]) \leq \tfrac{1}{2}\).
Example
Binomial Tail Bound

\(X \sim \text{Binomial}(k,p)\), \(\mathbb{E}[X]=kp\).

\[P\!\left(X > \frac{3k}{4}\right) \leq \frac{kp}{\tfrac{3k}{4}} = \frac{4p}{3}\]

For a fair coin (\(p=\tfrac{1}{2}\)):

\[P\!\left(\text{\# heads} > \frac{3k}{4}\right) \leq \frac{2}{3}\]
Example
Screw Pack — Markov Bound

\(\mathbb{E}[X] = 10 \times 0.01 = 0.1\). Markov gives:

\[P(X \geq 2) \leq \frac{0.1}{2} = 0.05\]

Loose bound (actual ≈ 0.004), but requires only the mean — no further distributional knowledge.

Definition
Tail Inequalities (Preview)
Markov is the weakest tail inequality. Stronger bounds (future sessions):
  • Chebyshev's inequality — uses variance, gives two-sided deviation bound.
  • Chernoff bounds — exponentially tight for sums of independent RVs.
The Binomial PMF peaks near \(kp\); tail inequalities quantify how fast mass falls away from this peak.
Practice Tail inequality problems in the problem set. Apply Markov before moving to Chebyshev and Chernoff.
