Week 1

History of Computation

Overview

Introduction to computing fundamentals and the origins of computation dating back thousands of years.

Key Topics

  • Ancient Computing: Pingala's binary notation system from 3000 BC using musical notes (laghu and guru)
  • Binary Numbers: First exposition of binary number systems through musical composition
  • Fibonacci Sequences: Computing the nth Fibonacci number using multiple approaches
  • Algorithm Design Ideology: Starting with simple recursive solutions and progressively optimizing
  • Optimization Techniques: Memory caching, iterative approaches, dynamic programming, and matrix multiplication

Core Concepts

Musical Binary Encoding:

  • Laghu (short note) = 0, duration 1 second
  • Guru (long note) = 1, duration 2 seconds
  • Number of songs with n notes = 2n

Algorithm Design Process:

  1. Start with the simplest approach (often recursive)
  2. Identify inefficiencies and bottlenecks
  3. Progressively optimize through better data structures and approaches
  4. Compare time and space complexity of different solutions
Week 2

Interval Scheduling

Problem Statement

Given one classroom and multiple teachers requesting time slots, find the maximum number of non-overlapping classes that can be scheduled.

Key Concepts

  • Greedy Algorithms: Make locally optimal choices at each step
  • Interval Representation: Each class defined by (start_time, end_time)
  • Overlap Detection: Two intervals overlap if one starts before the other ends

Solution Approaches

The course explores six different algorithms, with the optimal solution being:

Greedy Strategy (Algorithm 6): Always select the interval that ends first among remaining intervals.

Algorithm Steps

  1. Sort all intervals by end time
  2. Select the interval ending first
  3. Remove all overlapping intervals
  4. Repeat for remaining intervals

Why It Works

By selecting intervals that end earliest, we maximize the remaining time available for scheduling additional classes, leading to an optimal solution.

Week 3

Stable Marriage Problem

Problem Overview

The only algorithm to have won a Nobel Prize in Economics. Given n boys and n girls, each with preference rankings, find a stable matching where no pair would prefer each other over their current partners.

Stability Definition

A matching is stable if there are no two people who:

  • Are not matched to each other
  • Would both prefer each other over their current partners

Gale-Shapley Algorithm

A greedy algorithm that guarantees a stable matching:

  1. Each unmatched boy proposes to his highest-ranked girl who hasn't rejected him
  2. Each girl accepts the best proposal she has received (may upgrade later)
  3. Rejected boys propose to their next preference
  4. Continue until all boys are matched

Key Properties

  • Guaranteed Termination: Algorithm always terminates with everyone matched
  • Guaranteed Stability: The resulting matching is always stable
  • Boy-Optimal: Each boy gets the best partner possible in any stable matching
  • Girl-Pessimal: Each girl gets the worst partner she would have in any stable matching

Applications

  • Medical residency matching programs
  • College admissions systems
  • Job market assignments
  • Economic resource allocation
Week 4

Huffman Coding

Overview

A greedy algorithm for optimal lossless data compression using variable-length prefix-free codes.

Key Topics

  • Frequency-based encoding
  • Building optimal binary trees for compression
  • Prefix-free code construction
  • Greedy tree building strategy
  • Applications in file compression and data transmission

Algorithm Approach

Build a binary tree bottom-up by repeatedly combining the two least-frequent characters/symbols until a complete tree is formed.

Week 7

Longest Common Subsequence

Problem Definition

Find the longest subsequence common to two sequences (subsequences don't need to be contiguous).

Key Concepts

  • Dynamic Programming Solution: Build 2D table of subproblem solutions
  • Recurrence Relation: Define LCS in terms of smaller subproblems
  • Backtracking: Reconstruct the actual subsequence from the DP table

Applications

  • DNA sequence alignment in bioinformatics
  • Diff utilities in version control systems
  • Plagiarism detection
  • File comparison tools

Time Complexity

O(m × n) where m and n are the lengths of the two sequences.
